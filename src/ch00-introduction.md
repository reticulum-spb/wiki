# Введение

Это русскоязычная вики про **Reticulum Network Stack (RNS)** — сетевой стек для построения независимых децентрализованных сетей. 
Он позволяет передавать данные между устройствами через самые разные каналы связи: LoRa, Wi-Fi, Ethernet и многие другие.

Подробнее познакомиться с RNS можно в первом разделе: [1.1. Что такое Reticulum](ch01-getting-started/ch01-01-what-is-reticulum.md).
