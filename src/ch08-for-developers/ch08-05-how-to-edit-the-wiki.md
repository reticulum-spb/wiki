# Как редактировать вики

Страницы вики редактируются в репозитории [reticulum-spb/wiki — GitHub](https://github.com/reticulum-spb/wiki). 
Ветка `main` защищена, поэтому для редактирования необходимо создать pull request и получить approve.

Вики генерируется из Markdown файлов с использованием mdBook: [mdBook Documentation](https://rust-lang.github.io/mdBook/index.html).

Используются следующие плагины:
- [badboy/mdbook-last-changed — GitHub](https://github.com/badboy/mdbook-last-changed/tree/main)
